What you can do

Robot hub

Keep your Expert Advisors, versions and compiled EX5 files in one private place.

Cloud hosting

Start, stop and check the status of your robot on a Windows hosting machine. Status is only shown as running when that machine confirms it.

Client configuration

Set the symbol, timeframe and a preset (.set) file that your hosting machine passes to MetaTrader.

Read-only monitor

See balance, equity and open positions reported by your hosting machine. There are no trade buttons.

Licences

Issue and verify licence keys for the robots you publish.

Works on every screen

Install it on Android, iPhone or a computer. The app shell opens even without internet.

How it works

  1. Create an account. New accounts may be checked by an administrator first.
  2. Add your robot. Upload the compiled EX5 file. It is stored privately.
  3. Link an MT5 account. Passwords are encrypted on the server and only handed to the hosting machine when it starts your session. Live accounts are locked unless the administrator enables them.
  4. Configure and start. Pick the symbol and timeframe, then press Start. Watch the status and monitor.
